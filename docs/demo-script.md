# Two-minute judges' demo — NeuralShift

Preparation: run both servers, keep DEMO_MODE=true, open `/`, and have two bundled JPEGs ready for the bulk desk. Browser screenshot tests use separate data; normal demo history is retained in `data/`. Never enable real store credentials for a stage rehearsal without checking the destination first.

| Time | Do | Say |
| --- | --- | --- |
| 0:00–0:15 | Show the landing contact sheet and 25–40 minute baseline. | “A small seller can spend most of an hour making a product ready to sell. We turn a phone photo into a draft they can review. The impact figures are projections, not measured merchant outcomes.” |
| 0:15–0:35 | Open The studio, choose the steel bottle and press Develop. Point to the actual stopwatch and six trays. | “Every stage reports its status and elapsed time. This rehearsal uses labeled offline data. The same interfaces can call hosted SAM, FLUX, vision and search providers.” |
| 0:35–0:55 | Drag the comparison slider; use an arrow key; select Soft shadow and Lifestyle. | “These sample cutouts were prepared with local rembg. The backgrounds are real local composites in demo mode. A merchant checks the edges and product details before using any result.” |
| 0:55–1:15 | Switch Hindi and Marathi, return to English, edit the title and final price, save. Expand JSON. | “Copy is editable in three languages. A saved edit updates the actual draft and payload. Prices have visible comparable ticks; demo prices have no invented live source links.” |
| 1:15–1:30 | Select a store, tick approval, create the draft; show the DEMO ID/receipt. | “This action needs explicit approval. Today it saves a local demo draft. With a configured test store it creates a hidden draft and returns its Admin link; it does not publish to shoppers.” |
| 1:30–1:45 | Show Bulk desk with two photos, then Your ledger. | “A collection is queued one product at a time. Each item gets reviewed; selected drafts can be approved together. The ledger retains results and receipts.” |
| 1:45–2:00 | Show the calculator and architecture plate. | “Savings use the measured processing time and your own costs, with fees and review excluded. Stateless services, replaceable adapters and an RQ queue give us a practical path to larger catalogs.” |

Close with: “Faster, cheaper, better-looking catalogs without a studio or a copywriter.”

If a stage errors, show its retry button. If a provider is unavailable, point to the fallback reason. Do not describe local results or the projected conversion range as a successful live AI/merchant experiment.
